## 项目背景

这个示例说明如何在不改变网站结构的前提下，把非集成电路项目与 RFIC 项目放在同一个作品集中。当前只记录小车的系统架构，不虚构具体性能。

## 我的工作

- 将系统划分为感知、决策、执行和供电四个部分；
- 在模块集成前明确接口；
- 记录测试条件和失效模式；
- 让控制参数与固件一起进行版本管理。

## 系统架构

高层信号流程如下：

```text
传感器 -> 滤波 -> 控制器 -> 电机驱动 -> 小车
                   ^                    |
                   +------- 反馈 -------+
```

## 电子系统与固件

项目记录应包含供电树、连接器引脚、时序假设、固件状态机，以及传感器数据失效时系统应采取的安全行为。

## 验证方法

| 测试层级 | 示例问题 |
| --- | --- |
| 模块 | 每个传感器的输出范围是否有效？ |
| 接口 | 电平与时序是否兼容？ |
| 闭环 | 控制器能否从扰动中恢复？ |
| 系统 | 电源噪声是否影响传感器？ |

## 经验总结

当每个子系统都有简单的独立测试，并且日志统一使用物理单位时，系统集成问题会更容易定位。
